# 三队列分析方案

## 样本与对比

- GSE126848 用全部四组拟合 `~ sex + group`。指定 NASH / Obese 和 NASH / NAFL 为核心对比，NASH / Normal-weight 为参照。肥胖组是补充对照，组别和采样来源可能重合。组名沿用原研究。
- GSE225740 固定使用下列基因程序，评估与 NAS、纤维化分期的队列内等级相关。在表型文件能提供独立且可估计的协变量时报告调整分析。每个表型单独记录缺失和有效样本，不能将缺失视为 0 级。
- GSE164441 使用肿瘤 / 邻近组织的配对对比。文件审查须确认逐样本表达、计量方式和配对 ID。定量方式决定分析模型。

## 基因程序与阈值

人类 MSigDB 2025.1.Hs，固定三个 Hallmark 脂质代谢基因集和一个 Cordenonsi YAP 保守表达签名，详见 [programs.tsv](../config/programs.tsv)。该签名来自实验扰动研究，可评估相关转录模式；不能直接测定 YAP/TEAD 蛋白活性。

发现分析采用 DESeq2 的有限有符号 Wald 统计量进行 CAMERA 预排序竞争检验，基因集至少覆盖原始成员的 50% 且不少于 10 个。以同一发现队列的全部指定对比 × 基因集为 BH 家族，并以更高基因相关设定作敏感性分析。单基因 BH 值按各对比分开计算。

组织学关联用同一来源的基因集和队列内表达标准化得到程序分数。使用 Spearman 相关以及配套的区间估计，按两个预先列出的表型和四个程序统一调整。HCC 分析独立校正。所有模型先做适用性检查。三队列结果并列解释，效应定义有别，不能合并成一个效应量。
