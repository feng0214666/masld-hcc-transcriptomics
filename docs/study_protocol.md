# 分析方案与执行顺序

## 研究目标

在独立人肝脏队列中，分别评估脂质代谢、YAP/TEAD 相关转录程序与疾病分组、组织学严重程度及肿瘤状态的关系，再比较效应方向与可重复性。三类队列代表不同研究问题，不组成同一受试者纵向进展轨迹。

## 实施顺序

三个队列均已完成本轮分析。[三队列方案](three_cohort_plan.md)和[结果](three_cohort_results.md)记录实际模型、基因集和敏感性分析。

1. 下载并保留原始元数据及文件校验和。核对物种、组织、样本身份、数据量纲、患者配对和缺失字段。
2. 显式建立表达列到样本 ID 的映射。按队列导出规范 TSV，并记录转换脚本；不按列位置猜测样本。
3. 运行 QC。结合测序深度、样本相关、PCA 和可用批次信息调查异常。记录排除理由，不因不符合预期生物学方向而排除样本。
4. 在查看关联结果前确定主要对比、基因集版本和必要协变量。基础入口支持分组、可选患者配对及显式协变量；缺失、常量或秩不足会阻止拟合。交互、非线性和重复测量随机效应模型需另行实现。
5. 对合格原始整数计数运行 DESeq2。GSE164441 已确认有逐样本 FPKM，采用配对 limma，并改变取对数时的偏移量以检查敏感性。
6. 对预先确认的基因集计算队列内评分并检查覆盖率。GSE225740 用 Spearman 及自助重采样区间，按四个程序和两个表型统一进行 BH 校正。
7. 并列报告三个队列的效应、方向、区间、覆盖率与 FDR。主要对比与效应定义不同，结果表保留每项模型的统计量。

## 结果交付标准

- 每个正式队列运行保留输入来源、纳入排除清单、参数、校验和及软件版本。
- 报告每一对比的有效样本数、效应方向、效应量和多重比较规则。
- 区分预设分析和探索分析。YAP 相关转录程序需要独立文献核验，不从单个 YAP1 表达值推断蛋白活性。
- examples/demo 使用模拟表达。三个真实队列的最新成果见 examples/three-cohort。
