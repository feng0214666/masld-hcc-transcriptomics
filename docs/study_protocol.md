# 分析方案与执行顺序

## 研究目标

在独立人肝脏队列中，分别评估脂质代谢、YAP/TEAD 相关转录程序与疾病分组、组织学严重程度及肿瘤状态的关系，再比较效应方向与可重复性。三类队列代表不同研究问题，不组成同一受试者纵向进展轨迹。

## 实施顺序

1. 下载并保留原始元数据及文件校验和。核对物种、组织、样本身份、数据量纲、患者配对和缺失字段。
2. 显式建立表达列到样本 ID 的映射。按队列导出规范 TSV，并记录转换脚本；不按列位置猜测样本。
3. 运行 QC。结合测序深度、样本相关、PCA 和可用批次信息调查异常。记录排除理由，不因不符合预期生物学方向而排除样本。
4. 在查看关联结果前确定主要对比、基因集版本和必要协变量。当前基础入口只处理分组与可选患者配对；复杂模型需扩展代码并验证设计矩阵。
5. 对合格原始整数计数运行 DESeq2。GSE164441 需先判断公开 Cuffdiff 文件是否支持逐样本分析，另选相容量纲的方法。
6. 对预先确认的基因集计算队列内评分并检查覆盖率。均值 z 分数是描述性分析；组织学相关、多重检验和替代评分方法待补充。
7. 独立队列完成后，才设计效应量综合、异质性分析与敏感性分析。当前代码没有执行跨队列荟萃分析。

## 结果交付标准

- 每个正式队列运行保留输入来源、纳入排除清单、参数、校验和及软件版本。
- 报告每一对比的有效样本数、效应方向、效应量和多重比较规则。
- 区分预设分析和探索分析。YAP 相关转录程序需要独立文献核验，不从单个 YAP1 表达值推断蛋白活性。
- 当前已提交的表达示例全部为模拟数据。公开样本配对表属于真实元数据，不能当作已完成真实表达分析。
